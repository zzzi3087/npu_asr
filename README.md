# 实时字幕 · Intel NPU ASR

Windows 桌面实时转录与翻译软件。支持麦克风和桌面音频、双语字幕、透明桌面字幕、历史记录和导出。

已在 Intel 258v 笔记本成功运行

## 安装与使用

1. 在 [Releases](https://github.com/zzzi3087/npu_asr/releases/latest) 下载对应版本的 `LiveCaptions-<版本>-win64-setup.exe` 并安装。更新前先在托盘菜单选择“退出”。也可下载 portable ZIP，完整解压后运行 `LiveCaptions.exe`。
2. 需要 Windows 11 x64、兼容 OpenVINO 的 **Intel NPU** 和已安装的 Intel NPU 驱动。软件自带运行库，不需要另装 Python。不同型号、驱动的编译兼容性可能不同；没有 NPU 时不会改用 CPU/GPU 转录。
3. 首次启动检查模型；缺少的文件自动下载，并显示进度。可取消并在下次续传。下载后校验 SHA-256，完整模型会复用；首次 NPU 编译也需要等待。
4. 在设置中选择实时字幕模型、实时源语言、翻译语言和收音设备。设置中的模型与源语言仅用于实时收音；本地文件有独立选择。顶部的音频来源可快速切换麦克风/桌面音频，点击“开始收音”开始。
5. 翻译需要在设置的云服务页面填写自己的 API 地址、模型和密钥。兼容 OpenAI Chat Completions 和 Anthropic Messages 格式。仅转录时可关闭翻译，无需 API Key。
6. 默认关闭或最小化主窗口后转入右下角系统托盘，任务栏窗口隐藏，收音、翻译和桌面字幕继续运行。点击托盘图标恢复窗口；右键可停止收音、切换桌面字幕、进入设置或完全退出。图标可能在 Windows 的隐藏图标菜单中。
7. 在“设置 → 后台与托盘”可分别关闭上述行为。再次双击程序会恢复已有窗口，不会重复启动转录进程。
8. 转录本地文件时，点击左侧“音频文件 · 队列”，先选择“文件转录模型”和“文件语言”，再添加或拖入文件；可一次添加多个，查看进度、调整顺序、暂停队列、取消和重试。双击任务或点“查看字幕”可进入历史记录并导出。

安装程序当前没有代码签名证书。仅从本仓库 Releases 获取程序，并可用同页的 `SHA256SUMS.txt` 核对文件。

## 模型与下载

**安装 EXE、便携 ZIP 和源码均不包含模型权重。** 模型按需存到当前 Windows 用户的本地应用数据目录 `ParakeetNPUSubtitles/models`，不会放进安装目录。

| 模型 | 用途 | 下载来源 |
|---|---|---|
| Parakeet TDT 0.6B v2 | 英语，低延迟 | 固定版本的 FluidInference Hugging Face 仓库；分词器来自独立模型资源包 |
| Parakeet TDT 0.6B v3 | 25 种欧洲语言、自动标点与大小写、词级时间戳 | 固定版本的 FluidInference OpenVINO 导出与 NVIDIA 官方分词器 |
| Qwen3-ASR 1.7B | 多语言 | 本仓库独立的 `models-v1` Release，OpenVINO 社区转换版本 |
| Mega-ASR 1.7B | 多语言、抗噪对照 | 同上，合并抗噪分支，未启用动态路由 |
| Silero VAD | 语音活动检测 | 独立模型资源包，仅约 2 MB |

Parakeet 首次下载约 1.2 GB，Qwen/Mega 各约 3 GB；相同文件尽量复用。NPU 编译缓存另占磁盘空间。下载地址、原始来源、大小和 SHA-256 均列在 [model-catalog.json](resources/model-catalog.json)。Qwen 基座采用 Mega-ASR 作者发布的固定 Qwen3-ASR-1.7B 检查点副本，具体提交见清单。

四种 **ASR 神经网络** 都显式在 NPU 执行并检查执行设备，没有 CPU/GPU 转录回退。音频采集、分句、查表和文本解码使用 CPU；轻量 VAD 也在 CPU 执行。Parakeet v2 的确定性音频前处理可选 GPU，默认 CPU；v3 使用轻量 CPU FFT 与稀疏 Mel；这不改变 ASR 网络的 NPU 执行。

## Parakeet v3

在“设置 → 收音设置 → 实时字幕模型”选择 Parakeet v3；文件转录在“音频文件 · 队列”单独选择。首次按需下载约 1.23 GB，之后复用本地模型。v2 仍保留，升级不自动切换已有选择。

- 支持保加利亚语、克罗地亚语、捷克语、丹麦语、荷兰语、英语、爱沙尼亚语、芬兰语、法语、德语、希腊语、匈牙利语、意大利语、拉脱维亚语、立陶宛语、马耳他语、波兰语、葡萄牙语、罗马尼亚语、斯洛伐克语、斯洛文尼亚语、西班牙语、瑞典语、俄语、乌克兰语。**不支持中文。**
- 模型自行辨别语言并保留标点、大小写；界面的源语言选项仅提示分句和翻译，不会向 TDT 模型强制指定语言。支持语言见 [NVIDIA 模型说明](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3)。
- 使用与官方 8192 个词条逐项对应的词表和分词器，按 v3 的 blank 编号与时长输出解码。词语起止时间用于字幕，仍可能受噪声与识别错误影响。专业词表在设置中为 v3 单独启用。
- 当前社区 OpenVINO 导出固定为约 15 秒窗口。长文件通过有界滚动窗口处理，文件队列保留完整时间轴；**没有启用官方三小时本地注意力的单次推理模式**，不能将其显存或耗时指标套到这里。
- 本机发现短有效长度可能令此固定窗口导出漏掉语音，现统一使用完整窗口的长度参数，未使用的静音频谱直接填入常量；只对有音频的前缀做 FFT。字幕时间仍限制在真实音频内，标点不会把词结束时间延长到静音末尾。两分钟连续回放已检查窗口衔接与尾句。
- 已在本机 Intel NPU 验证英语、法语、德语、西班牙语及俄语短样本，encoder / decoder / joint 均报告 NPU。固定窗口修复后，四段非英语样本中三段与原始前处理文字一致，德语有一处词语差异；仍有识别错误，尚未验证全部语言或测量整机功耗，不能视为准确率或节电保证。

## 功能

- 本地音频批量转录，队列与每文件历史保存，支持 WAV、MP3、M4A/AAC、FLAC、OGG/Opus 等，也可读取视频的首条音轨。
- 系统托盘后台运行；隐藏时暂缓主页字幕排版，无动画或常驻轮询定时器。
- 设置窗口右上角显示当前程序版本，切换设置页面时始终可见，可选择复制。
- 多语言转录和翻译；Parakeet v2 仅支持英语，v3 支持 25 种欧洲语言；中文使用 Qwen/Mega。
- 动态音量增益、静音门限与分句策略；低音量提升不能恢复录音中已经缺失的信息。
- 领域词表：内置物理学、高能/理论物理、天体物理及暗物质术语，可编辑其他领域。Parakeet v2/v3 分别启用 TDT 解码词组偏置，v3 支持可分词的多语言术语；Qwen/Mega 使用上下文词表。增强效果取决于录音，词表过强也可能增加误报。
- 主界面双语字幕、历史搜索、重命名、删除、重试翻译、导出。
- 字幕上方的“不显示原文”“不显示译文”同时控制主页历史与桌面字幕，并记住选择；缺少译文时自动保留原文。两项都勾选则隐藏全部字幕文字。显示开关不删除历史，也不改变完整字幕的导出内容。
- 翻译服务失败时，字幕区只显示可用的文字，错误集中在右下角“翻译 API 不可用”提示中；悬停可看原因。成功重试后提示自动消失。
- 透明置顶桌面字幕：默认白字黑边、最近两句及翻译，可调整字体、颜色、字号、间距并预览。
- 四套完整工作台配色：雾白 / 墨夜（中性灰蓝）、米纸 / 暖岩（柔和暖色）。在“设置 → 工作台配色”点击预览卡片使用。
- 可开启“跟随系统明亮 / 深色”，在所选配色组内响应 Windows 应用颜色模式切换；无轮询或切换动画。关闭后恢复上次手动配色，点击卡片则固定该套配色。
- 支持自定义全局颜色、保存主题、配置导入/导出；跟随模式一并保存。升级保留已有手动配色，桌面字幕仍使用独立的颜色设置。
- 停止收音时不持续进行 ASR 推理；下载进度和界面刷新节流，无持续动画。

## 分句与实时延迟

四种模型共用缩写、小数、数字单位、未完成短语等轻量规则；模型自身的分词器和权重不变。

- v3.0.1 统一带时间戳与纯文本模型的句界判断，修复不同语言规则相互干扰造成的长字幕。自动模式通过有界词表选择保守规则，不再合并所有语言的禁断词；德语从句的句末动词、合法英文句末介词、句号后的小写新句及独立介词开头句能正确分开。补充希腊语问号、阿拉伯语与印地语句末标点。
- v3.2 减少“预览已有句号仍不提交”的阻塞：已有两个稳定后续词时，晚出现的句号可直接采用，不必再等第三轮；前缀中至多一两个词改写时，只有真实句界、稳定句尾和至少约 5/6 词语一致才允许整句确认，仍标记为边界待核。只检查有界的现有假设，不增加识别调用。补充英文讲解中 And / That 开始的新句及 “and so on” 等完整句尾。
- “设置 → 收音设置 → Parakeet 字幕确认等待上限”可设 **0.5–6 秒，默认 3 秒**，仅实时 v2/v3 生效，下次收音采用；本地文件保留原有保守确认。它控制不稳定前缀与带后文句界的等待目标，稳定句子会更早提交，未完成短语仍受保护。调低可能更早采用尚会改写的词，标记为边界待核；实际延迟还包含识别刷新、推理与翻译，不能保证在设定秒数内显示。
- 规则采用缓存和词表查询，不增加 ASR 推理或语言识别模型。68 组多语言合成正反例覆盖断句与不断句，仍保留跨窗口短语、缩写和数字单位保护。

- Parakeet 根据词时间与连续识别结果确认句子；取消普通长句的固定字数强制拆分，语音结束后不再额外重复等待。
- Qwen/Mega 连续两次识别都确认、且已有后文的完整前句可先提交。音频窗口到达上限时保留最后短语，窗口末尾的临时句号会在接续时处理，避免把窗口边界当成句子边界。
- 缩写（如 Dr.、Eq.）、小数、数字单位、部分英文姓名，以及明显未完成的短语受到保护。词形对齐保留重音字母、俄文和希腊文，并为法语、德语、西班牙语等增加明显未完成短语的保护；这些规则不等于完整语法分析。
- “设置 → 收音设置 → 分句策略”可选择均衡、整句优先或低延迟。均衡模式启用低音量增强时，语音结束判断约需 0.77 秒；Parakeet 的末句连续两次保持一致、完整且词时间覆盖最新语音时，可使用约 0.61 秒门限，无额外预览推理；有新语音、短语不完整或时间戳不可靠时保留普通门限。这只是停顿门限，实际字幕延迟还包含模型推理、稳定确认及翻译耗时。未完成短语会等待后文，停止收音则提交剩余内容。
- 优先使用 TDT 的词结束时间生成字幕时间轴；时序对齐预先计算词形，减少循环内重复工作。缓存词形与标点判断，空闲时仅在期限到达后检查待定句子。Parakeet 连续讲话只移除已确认的旧音频，保留最近上下文，减少重复解码；不增加分句模型或后台轮询。
- 实时收音默认开启“长句先译”：说话约 6 秒、已有足够且连续两次一致的前缀后，把稳定的一部分显示在正文并提前翻译。每句最多预译次数可设为 **1–10 次，默认 2 次**；预译最短间隔可设为 **0.5–5 秒，默认 1 秒**。整句确认后的翻译不计入次数。后续预译必须有更多稳定文字，不重复请求相同前缀，也不额外运行 ASR；实际间隔受识别更新和翻译服务速度影响。更新预译时保留上一版，成功后原位替换。整句确认后正常提交全文翻译，成功后一次性替换临时字幕，主页和桌面字幕同步；失败时暂时保留已有临时译文，右下角提示并可重试。
- “设置 → 翻译服务 → 长句先译”可关闭此功能，下面可调整每句最多预译次数和最短间隔，保存后下次收音生效，支持配置导入导出。次数是上限，不保证用满；翻译队列繁忙、服务已不可用或翻译关闭时跳过预译。临时请求使用较短超时且不重试。临时字幕不写入历史或导出，完整原文照常保存；退出软件后可在历史中补译完整句子。本地文件转录只翻译确认的句子，不产生额外预译请求。

分句仍是启发式判断，无法保证所有口音、停顿和模型误标点都正确。Qwen/Mega 的字幕时间为估算时间。上述规则同时用于实时字幕和本地文件转录，原有历史记录不会重写。

若模型原文完全缺少句末标点，仍可能形成较长字幕，不会仅凭字数频繁强行截断。另已发现 Mega 在部分德语连续音频上会触发生成长度保护；原 NumPy 增益和 C++ 路径都可复现，并非此版本引入。此时可改用 Parakeet v3 或 Qwen，软件不会回退 CPU/GPU 转录。

## 原生音频处理

v3.0.1 将每个音频块的 RMS、峰值、动态增益平滑与限幅合并为小型 C++ 内核，减少 Python/NumPy 调用和临时数组。平滑系数只在块大小变化时计算；不增加工作线程、定时器或 ASR 调用。界面、队列和配置保留 Python，模型推理仍由 OpenVINO 的原生 NPU 运行库执行。

安装包自带该 DLL；从源码运行时未编译 DLL 也能使用 NumPy 实现。3,600 组状态连续的对照覆盖静音、弱音、限幅、配置变化、非连续数组与不同块长，最大样本绝对差约为 1.2×10⁻⁷。该优化减少的是音频处理计算，尚未实测整机瓦数或电池续航，不能换算成同等节电比例。

## 本地文件与预处理

Windows 安装包和便携版自带 FFmpeg/ffprobe，无需额外安装。每个文件显示“检查响度 → 预处理 → NPU 转录”的阶段进度与总体进度；模型首次下载/加载也会在主页显示。

- 文件转录的模型与源语言在该界面独立选择、单独保存，与设置中的实时字幕模型和实时语言互不影响。默认 Parakeet / 自动（仅英语）；欧洲语言可选 v3，中文等语言可选 Qwen/Mega。选择只用于之后添加的文件，已有任务和重试仍使用各自添加时的模型、语言与词表。增益、专业词表配置和翻译服务继续共用设置。
- 转录前测量时长、采样率、声道、LUFS、真峰值、RMS 和直流偏置。
- 默认按需做恒定音量缩放：目标约 −20 LUFS，偏差不足 2 dB 时通常保持原音量；提升最多 24 dB，且受 −2 dBTP 峰值余量限制。受峰值或增益限制时可能达不到目标，识别阶段仍可使用已有的动态增益设置。
- 静音不放大；已削波的文件显示提示。混合声道出现明显抵消时自动选取较强声道，避免反相立体声把语音抵消。
- 统一为 16 kHz 单声道浮点 PCM；兼容且无需调整的 WAV 直接复用。可选 80 Hz 低频过滤，默认关闭；不默认做强降噪、不剪静音、不改变播放速度或时间轴，原文件不会被改写。
- 分块读取，临时缓存每小时约 230 MB，任务结束/取消后清理。队列暂停会等待当前文件结束；“取消当前”会终止 FFmpeg，或等待正在执行的 NPU 推理结束，已生成字幕保留。
- 文件与实时收音串行使用同一个 NPU。收音时添加的文件先排队，停止收音后开始；也可暂停文件队列再收音。翻译在后台继续，显示“转录完成”不表示网络翻译已经全部结束。
- 队列只在本机保存文件路径和任务配置，重启后等待用户继续；中断项可重试，会生成新的历史记录，不覆盖上次已保存的字幕。

所有 ASR 网络仍仅在 NPU 执行。FFmpeg 解码、响度分析、采样转换和轻量 VAD 使用 CPU；FFmpeg 使用低优先级和受限线程，不引入常驻后台进程。

## 隐私与本地数据

- 麦克风/桌面音频在本机转录，程序不向云端发送音频，不默认保存录音。
- 开启翻译后，字幕文字及有限上下文会发送至你设置的服务地址。使用前请确认该服务符合你的需求。
- API Key 存放在 Windows 凭据管理器，不写入普通设置文件或配置导出。历史字幕与设置存在本机用户目录；导出历史时会包含所选字幕。
- 下载只访问清单所列的公开模型地址，不附带翻译服务密钥。
- 本地文件的音频内容和队列路径不上传；若启用翻译，转录后的文字仍会发给你配置的服务。

## 从源码运行和构建

使用 64 位 Python 3.13，创建虚拟环境后：

```powershell
python -m pip install -r requirements/runtime.txt
python main.py
```

源码运行本地文件功能还需要 `ffmpeg`、`ffprobe` 在 PATH 中，也可将 `PARAKEET_FFMPEG_DIR` 指向包含这两个程序的目录。

可选的原生增益需要先运行 `python tools/build_native.py`，生成 `build/native/audio_native.dll`。编译机需安装 Visual Studio C++ Build Tools 的 x64 工具集；终端用户无需安装。可用 `PARAKEET_NATIVE_AUDIO=0` 临时停用以进行对照。

构建 Windows 包需要同一运行环境、`packaging/requirements-build.txt` 和 Inno Setup 7：

```powershell
python -m pip install -r packaging/requirements-build.txt
python tools/build_native.py
python tools/prepare_build.py
python tools/prepare_media_tools.py
python -m PyInstaller --noconfirm packaging/LiveCaptions.spec
ISCC /DBundleDir="<absolute-path-to-dist/LiveCaptions>" /DReleaseDir="<absolute-output-folder>" packaging/installer.iss
```

模型转换开发另见 `tools/export_qwen_npu.py`、`tools/export_mega_npu.py` 和 `requirements/conversion.txt`，普通用户无需转换。`PARAKEET_DATA_DIR` 和 `PARAKEET_MODEL_ROOT` 可覆盖本地数据/模型目录，主要用于隔离测试。

## 源码目录

```text
main.py        源码启动入口
src/           程序代码（界面、音频、模型与翻译）
native/        C++ 音频增益内核源代码
tests/         隔离测试与回归检查
tools/         模型转换和构建辅助工具
packaging/     Windows 打包配置
resources/     模型下载清单、图标与公开元数据
requirements/  运行和转换依赖
licenses/      第三方许可与版权说明
```

离线检查：

```powershell
python tests/check_model_downloads.py
python tests/check_parakeet_v3.py
python tests/check_segmentation.py
python tests/check_multilingual_boundaries.py
python tests/check_submission_latency.py
python tests/check_native_audio.py --require-native
python tests/check_progressive_captions.py
python tests/check_file_processing.py
python tests/check_file_queue.py
python tests/check_caption_visibility.py
python tests/check_tray.py
python tests/check_main_layout.py
python tests/check_model_startup.py
python tests/check_audio_ui.py
python tests/check_ui_stability.py
```

安装后的可执行文件另提供 `--smoke-test --report <local-json-path>`，用于隔离测试界面、音频运行库和 NPU。加 `--model parakeet --wav <wav-path>` 可验证真实模型转录；缺少模型会下载。测试不会启动麦克风收音。
